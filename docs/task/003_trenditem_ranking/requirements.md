# Task 003 Requirements - TrendItem Ranking and LLM Wiki Synthesis

## Purpose

Task 003 turns ingested source items into ranked daily digest candidates and LLM Wiki synthesis records.

This task does not collect new external sources. It uses Task 001 storage and Task 002 ingestion output.

## Inputs

- `TrendItem`
- `SourceEvidence`
- source credibility from Source Registry
- optional future social signal lineage from Task 007

## Required Outputs

1. `summary`
2. `whyItMatters`
3. `practicalImpact`
4. `trendCategory`
5. `actionLevel`
6. `confidence`
7. `importanceScore`
8. `sourceLineage`
9. `confirmationStatus`
10. `contradictionNotes`
11. `stalenessPolicy`
12. daily digest candidates

## Enum Requirements

`actionLevel`:

- `do_now`
- `do_next`
- `watch_later`
- `needs_confirmation`

`confirmationStatus`:

- `confirmed`
- `official_only`
- `needs_confirmation`
- `conflicting`
- `excluded`

`trendCategory`:

- `model`
- `coding_agent`
- `product`
- `open_source`
- `benchmark`
- `infra`
- `safety`
- `business`
- `research`

## Trust Gate

Social or trusted individual signals must not be promoted as confirmed facts unless connected to an official source, official GitHub release, paper, benchmark page, or source-of-record.

Rules:

1. `confirmationStatus = needs_confirmation` cannot become `do_now`.
2. `needs_confirmation` without official lineage is capped at `watch_later`.
3. Slack-ready digest candidates must be `confirmed` or `official_only`.
4. social-only items can influence velocity but not factual confidence.

## Karpathy LLM Wiki Mapping

- raw source: Task 002 cache and `SourceEvidence`
- wiki synthesis: Task 003 assessment fields
- schema: this task's enums, trust gate, and scoring rules
- query/index/lint: start with minimal query/index output; full lint can be a later task

## Acceptance Criteria

- deterministic ranking exists before any LLM provider is added.
- digest candidates can be generated by date.
- source lineage is visible in output.
- `needs_confirmation` gate is tested.
- generated records preserve original source evidence links.
