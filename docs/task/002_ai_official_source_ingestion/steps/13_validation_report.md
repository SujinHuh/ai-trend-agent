# Step 13 - Validation Report

## Purpose

Record what was verified and what risk remains.

## Required Content

- implementation scope
- commands run
- test results
- source config validation result
- parser fixture results
- manual ingestion command
- DB path
- cache path
- source result counts
- failed sources
- remaining risks

## Review Checklist

- report distinguishes fixture validation from live-source validation.
- source failures are visible.
- known HTML selector drift risk is recorded.

## Done Criteria

- validation report is complete.
- phase status matches verified results.
- work log has a validation entry.
