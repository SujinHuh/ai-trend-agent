구현 내용

날짜별 Digest

저장된 날짜와 membership을 기준으로 이전·다음 digest와 Top Signals를 조회합니다.

검색과 필터

query, domain, category, source 조합을 GET URL에 보존하고 결정론적으로 정렬합니다.

안전한 SSR

DB 문자열을 escape하고 http(s) 원문만 허용하며 빈 결과와 typed 오류를 처리합니다.

GCE 운영

전용 계정, read-only SQLite snapshot, loopback process와 nginx exact route로 분리했습니다.

운영·보안 경계

  • 뉴스 process는 127.0.0.1:4174에만 bind합니다.
  • /var/lib/ai-trend-news/llm-wiki.sqlite를 read-only로 엽니다.
  • Slack webhook과 cron secret을 public process에 전달하지 않습니다.
  • SQLite snapshot은 online backup, integrity check, atomic rename으로 게시합니다.
  • /cron은 news service에서 제공하지 않습니다.

독립 검수 반영

Production DB 경로

일반 external-path opt-in과 분리된 news 전용 허용 변수를 적용했습니다.

Network bind

localhost 해석 차이를 제거하고 IPv4 loopback만 허용했습니다.

DB publish

WAL raw copy와 in-place overwrite 대신 검증된 atomic snapshot을 사용합니다.

Responsive UI

desktop/mobile overflow, form, empty/error 화면을 실제 브라우저로 검증했습니다.
