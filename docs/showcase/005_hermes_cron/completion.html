Task 005 Hermes Cron

Hermes 호환 POST /cron 실행 경로를 추가하고, daily digest 흐름을 dry-run/send 모드로 안전하게 실행할 수 있게 만들었습니다. 방향성은 정해진 시간에 AI 트렌드를 Slack으로 알려주는 것입니다.

Built

  • cron_runs audit table
  • runHermesCron worker
  • POST /cron endpoint
  • cron:run, cron:serve
  • active send claim and idempotency guard
  • production-required cron secret guard
  • project-scoped DB/config/cache/output paths

Safety

  • default mode is dry_run
  • send mode requires explicit request
  • missing webhook fails before network
  • dry-runs do not block later sends
  • duplicate successful sends are idempotency guarded
  • concurrent send claims are DB guarded
  • HTTP response output is minimized and redacted
  • HTTP force bypass is disabled unless CRON_ALLOW_FORCE=true
  • external filesystem paths are blocked by default

Security Re-review

High risks fixed:
- cron auth fail-open
- response overexposure

Medium risks fixed:
- active claim raw DB error
- body size missing
- HTTP force bypass
- cron_runs drift check
- path scope gaps

dry-run은 webhook 없이 성공했습니다. send mode는 webhook이 없어서 네트워크 전 안전하게 실패했습니다.
